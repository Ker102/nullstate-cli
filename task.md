# Public Documentation Translation

English documentation remains authoritative. Translate complete maintained public
documents into es, zh-CN, fr, ja, de, and pt-BR under
`docs/i18n/<locale>/<source-path>`. Never substitute summaries for full mirrors.

Scope: README, contribution/security/community documentation, operational guides,
public references, examples, and architectural decisions. Record pending maintained
documents separately from excluded internal plans, handoff/progress notes, generated
run evidence, private local records, vendor content, and executable schema/template
assets. Preserve commands, code blocks, identifiers, versions, URLs, safety limits,
and distinctions between proven runtime evidence and future/experimental work.

Constraints: preserve other changes; no scenario execution, deployments, or
live-cloud validation. On 2026-10-11, the owner authorized publishing the existing
readiness branch and these translations as a pull request, not a main-branch merge.

Success: complete mirrors are accurately inventoried with English source hashes;
language switchers and internal links resolve; local validator and focused tests
pass; incomplete coverage is reported explicitly. No software behavior changes.
