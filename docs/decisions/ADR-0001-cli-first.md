# ADR-0001: CLI-first hackathon product

## Status

Accepted.

## Context

The hackathon has a 48-hour timeline and the core value is a technical security validation loop.

## Decision

Build a Python CLI first instead of a web UI.

## Consequences

- Faster to implement and demo.
- Easier to show logs, diffs, attacks, and reports in one flow.
- Less visual polish than a web dashboard.
