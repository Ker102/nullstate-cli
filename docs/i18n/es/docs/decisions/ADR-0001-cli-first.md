# ADR-0001: Producto del hackathon centrado en CLI

<a id="status"></a>
## Estado

Aceptado.

<a id="context"></a>
## Contexto

El hackathon dura 48 horas y el valor central es un ciclo técnico de validación de seguridad.

<a id="decision"></a>
## Decisión

Crear primero CLI Python en lugar de UI web.

<a id="consequences"></a>
## Consecuencias

- Implementación y demo más rápidas.
- Logs, diffs, ataques e informes en un flujo.
- Menos acabado visual que un panel web.
