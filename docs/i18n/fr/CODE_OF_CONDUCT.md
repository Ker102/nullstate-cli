# Code de conduite

Rester respectueux, direct et axé sur les preuves. La sécurité peut inclure des scénarios adversariaux, mais la collaboration doit rester professionnelle et constructive.

Ne pas utiliser les exemples nullstate contre des systèmes qui ne vous appartiennent pas ou que vous n'êtes pas autorisé à tester.
