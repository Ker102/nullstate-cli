# ADR-0001 : Produit hackathon CLI d'abord

<a id="status"></a>
## État

Accepté.

<a id="context"></a>
## Contexte

Hackathon de 48 heures ; valeur centrale : boucle technique de validation sécurité.

<a id="decision"></a>
## Décision

Construire d'abord une CLI Python, pas une UI web.

<a id="consequences"></a>
## Conséquences

- Implémentation/démo plus rapides.
- Logs, diffs, attaques, rapports dans un flux.
- Moins de finition visuelle qu'un dashboard web.
