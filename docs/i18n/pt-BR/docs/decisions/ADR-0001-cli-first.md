# ADR-0001: Produto hackathon CLI primeiro

<a id="status"></a>
## Status

Aceito.

<a id="context"></a>
## Contexto

48 horas; valor principal é ciclo técnico de validação.

<a id="decision"></a>
## Decisão

Criar CLI Python antes de UI web.

<a id="consequences"></a>
## Consequências

- Implementação/demo mais rápidas.
- Logs, diffs, ataques, relatórios no mesmo fluxo.
- Menos polimento visual que painel web.
