# ADR-0001: CLI-first-Hackathonprodukt

<a id="status"></a>
## Status

Angenommen.

<a id="context"></a>
## Kontext

48 Stunden; Kernwert ist technische Sicherheitsvalidierung.

<a id="decision"></a>
## Entscheidung

Zuerst Python-CLI statt Web-UI.

<a id="consequences"></a>
## Folgen

- Schnellere Umsetzung/Demo.
- Logs, Diffs, Angriffe, Berichte in einem Ablauf.
- Weniger visuelle Ausarbeitung als Webdashboard.
