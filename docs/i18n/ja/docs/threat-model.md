# 脅威モデル - nullstate

<a id="system-overview"></a>
## システム概要

ローカル優先 CLI が IaC を分析し、サンドボックス攻撃を実行/模擬し、レッド/ブルーモデルを使い、コピー内で修正し証拠を出力します。

<a id="assets"></a>
## 資産

| 資産 | 重要性 | 機密度 |
|---|---|---|
| IaC ソース | アーキテクチャと秘密の露出 | 中/高 |
| ワークスペース | コピー IaC と修正 | 中 |
| モデル API キー | エンドポイント接続 | 高 |
| LocalStack トークン | Azure イメージ接続 | 高 |
| レポート | 公開証拠 | 処理後低/中 |
| ID/委任グラフ | 権限、委任、ツール、到達先を露出 | 高 |
| 記憶/ツール設定 | 指示、認証情報、検索データ、信頼連携情報の可能性 | 高 |

<a id="trust-boundaries"></a>
## 信頼境界

- 利用者シェルから CLI。
- CLI から Docker/LocalStack/kind。
- CLI からモデル。
- AI からクラウド ID、ツールゲートウェイ、下流サービス、委任文脈。
- 生成攻撃からローカル実行ディレクトリ。
- 文書から公開インターネット。

<a id="actors"></a>
## 主体

| 主体 | 目的 | 信頼 |
|---|---|---|
| 操作者 | ローカル IaC 検証 | 信頼 |
| 外部攻撃者 | 公開成果物/サンドボックス悪用 | 非信頼 |
| レッド代理 | 攻撃経路発見 | 部分信頼 |
| ブルー代理 | 修正生成 | 部分信頼 |
| 顧客 AI | 自身/委任 ID でクラウド操作 | 部分信頼 |
| 侵害ツール/記憶 | 判断操作/権限悪用 | 非信頼 |
| 侵害依存 | 悪意コード実行 | 非信頼 |

<a id="threats"></a>
## 脅威

| 脅威 | 影響 | 可能性 | 制御 | 証拠 |
|---|---|---|---|---|
| 誤って実クラウドへ到達 | 高 | 中 | 既定 LocalStack/プランのみ | CLI 対象文書 |
| 秘密をコミット | 高 | 中 | `.gitignore`、`.env.example`、SECURITY.md | ファイル |
| サンドボックス脱出 | 高 | 中 | 許可コマンド/コピー | モジュール |
| 依存侵害 | 高 | 中 | Dependabot、pip-audit、レビュー | ワークフロー |
| 誤誘導モデル | 中 | 高 | 決定論的検出/パッチ検証 | テスト |
| 侵害 AI のクラウド権限悪用 | 高 | 中 | ID グラフ、最小権限、委任分離、管理検証 | 将来 ID アダプター |
| 特権代理が混乱した代理になる | 高 | 中 | 呼出者/委任帰属、ポリシー、ツール認可 | 将来 ID アダプター |
| 共有 ID が帰属を隠す | 高 | 中 | 可能なら代理/実行/ツール別証拠要求 | 将来一覧 |
| 外部ホスト侵害でテナント ID は有効 | 高 | 中 | 態勢、短命連携、認可ゲート、最小権限、失効 | 将来収集 |
| 偽造/古い態勢を受理 | 高 | 中 | 署名、発行者、時刻、鮮度、高影響では失敗時拒否 | 将来検証 |

<a id="abuse-cases"></a>
## 悪用例

- 誤って本番 Terraform state を対象。
- 悪意依存が CI 環境変数を読む。
- レポートに本物トークン/私設 URL。
- レッドが LocalStack 外を提案。
- コンテナが予期せぬポート公開。
- プロンプト注入で合法ツールに有害パラメーター。
- 低権限利用者の代理が広いサービス権限を保持/取得。
- 侵害 MCP、連携、プラグイン、記憶、文書が行動を変更。
- 複数代理が特権 ID を共有し変更者不明。
- 下流資格の範囲/期間が元タスクを超過。
- 第三者代理が脆弱ホストの有効 ID で承認権限を悪用。
- イメージ署名/ハードウェア証明をアプリ全体の安全保証と誤解。

<a id="residual-risks"></a>
## 残留リスク

- Docker の安全性は操作者マシン依存。
- LocalStack Azure と実 Azure は機能差があり得る。
- GitHub 設定前は CI でブランチ保護を強制できない。
- 提供者固有 ID と委任は進化中で固有証拠/一覧が必要。

<a id="next-improvements"></a>
## 次の改善

- Azure Emulator 利用権取得後に実行検証。
- 提供者別許可リストと承認を伴う場合のみ実クラウド追加。
- AWS/Azure のネイティブ代理、通常ワークロード、委任利用者、ツール、下流資格の一覧。
- 外部態勢を検証済み、観測、操作者証言、推論、不明に明示分類。
