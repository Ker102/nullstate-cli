# ADR-0001：CLI 優先ハッカソン製品

<a id="status"></a>
## 状態

採用。

<a id="context"></a>
## 背景

48 時間であり価値は技術的安全検証ループ。

<a id="decision"></a>
## 判断

web UI より先に Python CLI。

<a id="consequences"></a>
## 結果

- 実装/デモが速い。
- ログ、差分、攻撃、報告を一連で表示。
- web ダッシュボードより視覚的完成度が低い。
