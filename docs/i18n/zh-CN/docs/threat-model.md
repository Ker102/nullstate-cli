# 威胁模型 - nullstate

<a id="system-overview"></a>
## 系统概览

nullstate 是本地优先 CLI，分析 IaC、运行或模拟沙箱攻击、使用红/蓝模型、在复制工作区修复并输出证据。

<a id="assets"></a>
## 资产

| 资产 | 重要性 | 敏感度 |
|---|---|---|
| IaC 源码 | 可能泄露架构和秘密 | 中/高 |
| 运行工作区 | 包含复制 IaC 和修复 | 中 |
| 模型 API key | 访问模型端点 | 高 |
| LocalStack token | 访问 Azure 镜像 | 高 |
| 报告 | 公开证据 | 脱敏后低/中 |
| 代理身份/委托图 | 揭示权限、用户委托、工具和可达系统 | 高 |
| 代理记忆/工具配置 | 可能包含指令、凭据、检索数据和可信集成细节 | 高 |

<a id="trust-boundaries"></a>
## 信任边界

- 用户 shell 到 CLI。
- CLI 到 Docker/LocalStack/kind。
- CLI 到模型端点。
- AI 代理到云身份提供商、工具网关、下游服务和用户委托上下文。
- 生成攻击脚本到本地运行目录。
- 仓库文档到公共互联网。

<a id="actors"></a>
## 参与者

| 参与者 | 目标 | 信任级别 |
|---|---|---|
| 操作者 | 验证本地 IaC 安全 | 可信 |
| 外部攻击者 | 滥用公开产物或暴露沙箱 | 不可信 |
| 红队代理 | 寻找沙箱攻击路径 | 部分可信 |
| 蓝队代理 | 生成修复 | 部分可信 |
| 客户 AI 代理 | 用自身或委托身份操作云资源 | 部分可信 |
| 受入侵工具/记忆源 | 影响决策或滥用权限 | 不可信 |
| 受入侵依赖 | 执行恶意代码 | 不可信 |

<a id="threats"></a>
## 威胁

| 威胁 | 影响 | 可能性 | 控制 | 证据 |
|---|---|---|---|---|
| 意外命中真实云 | 高 | 中 | 默认 LocalStack/仅计划 | CLI 目标文档 |
| 提交秘密 | 高 | 中 | `.gitignore`、`.env.example`、SECURITY.md | 仓库文件 |
| 代理逃逸沙箱 | 高 | 中 | 允许后端命令、复制工作区 | 沙箱模块 |
| 依赖入侵 | 高 | 中 | Dependabot、pip-audit、依赖审查 | workflow |
| 误导模型输出 | 中 | 高 | 确定性检测与补丁验证 | 测试 |
| 受入侵代理滥用云权限 | 高 | 中 | 身份图、最小权限、委托隔离、受控验证 | 未来身份适配器 |
| 特权代理成为混淆代理 | 高 | 中 | 调用者/委托归因、策略、逐工具授权 | 未来身份适配器 |
| 共享运行时身份掩盖归因 | 高 | 中 | 支持时要求独立代理/运行时/工具证据 | 未来身份清单 |
| 外部宿主入侵但租户身份仍有效 | 高 | 中 | 态势、短期联合、授权网关、最小权限、撤销 | 未来收集器 |
| 接受伪造或过期态势 | 高 | 中 | 签名、签发者验证、时间戳、新鲜度、失败时拒绝高影响访问 | 未来验证器 |

<a id="abuse-cases"></a>
## 滥用案例

- 用户误指向生产 Terraform state。
- 恶意依赖在 CI 读取环境变量。
- 报告含真实 token 或私有端点。
- 红队建议 LocalStack 范围外操作。
- 沙箱容器意外暴露端口。
- 提示注入让云管理代理用有害参数调用合法工具。
- 低权限用户的代理保留或获得更广服务主体权限。
- 受入侵 MCP、连接器、插件、记忆或文档重定向行为。
- 多代理共享特权运行时身份，掩盖修改发起者。
- 下游凭据范围或寿命超出任务。
- 第三方代理从易受攻击宿主提交有效身份并恶意使用获批权限。
- 操作者把镜像签名/硬件证明视为整个应用安全的证明。

<a id="residual-risks"></a>
## 残余风险

- 本地 Docker 安全依赖操作者机器。
- LocalStack Azure 覆盖可能与真实 Azure 不同。
- GitHub 配置前 CI 无法强制分支保护。
- 原生代理身份和委托流程仍演变，需要提供商特定清单和证据。

<a id="next-improvements"></a>
## 后续改进

- 账户有 Azure Emulator 授权时执行 LocalStack Azure 实际验证。
- 仅有提供商特定端点允许清单与批准流程时添加真实云适配器。
- 添加 AWS/Azure 身份清单，覆盖原生代理、常规工作负载、委托用户、工具、下游凭据。
- 添加外部态势证据，明确分类为已验证、已观察、操作者证明、推断、未知。
